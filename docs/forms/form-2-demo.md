## 1. 메뉴 경로와 정확한 양식 이름

- 정확한 양식 이름: **`제품 출고 요청서`** (양식 번호 19) — ①과 같은 양식
- "데모용"은 별도 양식이 아닙니다. 제목과 거래처·End User 값으로 구분합니다.
- 메뉴 경로: 전자결재 → ✏️(새 문서) → 결재유형 `내부결재` → 양식구분 `- 공통 -` → 양식선택 `제품 출고 요청서`
- 문서번호 형식: `제품 출고 요청서 영업 2026-NNNN`
- 제목 관례: **`제품 출고 요청서_영업 데모용`** (최근 데모 건은 모두 이 제목 그대로)
  - 2026년 9월 액세서리 건은 `제품 출고 요청서_데모시연용 악세서리 출고_영업용/260915`처럼 쓴 적도 있습니다.
- 순서: ③의 `기안품의서_데모시연용 제품 출고_영업용`을 먼저(또는 같은 날) 상신하고, 이 출고 요청서에 첨부문서로 연결합니다.

## 2. 입력 칸 전체 목록

작성 화면 왼쪽 패널과 본문 표의 칸 구성은 ①과 같습니다(`form-1-sales.md` 2번). 본문은 모두 글로 입력하며 드롭다운·필수 표시가 없습니다. 데모 건에서 달라지는 값만 적습니다.

| 칸 | 입력 방식 | 데모 건에서 넣는 값 |
|---|---|---|
| 요청일자 / 출고예정 | 글(날짜) | `26/11/23` |
| 담당자 / 요청부서 | 글 | `영업/라이언` |
| 출고부서 | 글 | `브커/스타` |
| 출고유형 | 글 | `데모용` 또는 `재고이관` (출고 완료된 데모 건에서 둘 다 씀) |
| 제품군 / 품목 / 품번코드 | 글 | `P3000A / LF-P3000A`, `P1000 / LF-P1000`, `E1000세트 / LINKFLOW BOLD / LF-E1000` |
| 요청수량 | 글(숫자) | 수량 |
| 거래처 | 글 | `영업 데모용` |

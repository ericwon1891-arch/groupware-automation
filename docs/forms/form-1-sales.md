# ① 제품출고 요청서 (일반판매)

> 조사일: 2026-11-24 · 한비로 전자결재(linkflow.hanbiro.net)를 보기만 해서 확인
> 원문의 금액·개인 연락처는 [가림] 처리(이번 문서에는 해당 내용 없음)

## 1. 메뉴 경로와 정확한 양식 이름

- 정확한 양식 이름: **`제품 출고 요청서`** (양식 번호 19)
- "일반판매"는 별도 양식이 아닙니다. 같은 양식을 쓰고 제목과 출고유형(`판매`)으로 구분합니다.
- 메뉴 경로: 전자결재 → 오른쪽 위 ✏️(새 문서) → 결재유형 `내부결재` → 양식구분 `- 공통 -` → 양식선택 `제품 출고 요청서`
- 문서번호 형식: `제품 출고 요청서 영업 2026-NNNN`
- 보존년한: 영구 · 문서공개: 비공개
- 제목 관례: `제품 출고 요청서_<품목/모델>_<거래처(현장)> / <YYMMDD>`
  - 예: `제품 출고 요청서_P1000 바디캠_GS구미열병합발전 / 261123`
  - 예: `제품 출고 요청서_P3000 5EA(정현에프엠씨)/261117`
  - 해외 건은 `제품 출고 요청서_미국 Triton`처럼 국가+거래처만 쓰기도 합니다.

## 2. 입력 칸 전체 목록

### 2-1. 작성 화면 왼쪽 패널(시스템 칸)

| 칸 | 필수 | 입력 방식 | 선택지·기본값 |
|---|---|---|---|
| 결재유형 | 필수 | 라디오 | `내부결재`(기본) / `협조결재` |

| 양식선택 | 필수 | 드롭다운 | 공통 양식 32종 중 `제품 출고 요청서` (기본값은 `ECO`) |
| 결재선 불러오기 | 선택 | 드롭다운 | `빈결재선` / `지출결의서` / `외근신청서` (저장된 결재선) |
